# L4D2 管理面板（裸机部署版）

一个现代化、响应式的 Left 4 Dead 2 服务器可视化管理面板：部署、实例、插件、地图、备份一站管理，专为服主设计。不依赖 Docker，可直接部署在轻量云服务器（Ubuntu/Debian/CentOS）上。

技术栈：Flask + 原生 HTML/CSS/JS + Bash Script。

## ✨ 功能特性

- **仪表盘**：服务器核心状态实时监控（CPU/内存/磁盘/网络）
- **一键部署**：网页调用 SteamCMD 下载/更新服务端，匿名下载无需 Steam 账号，实时日志
- **实例管理**：网页在线新增/编辑/删除服务器实例，无需修改任何脚本
- **插件管理**：压缩包"识别导入"、批量装卸、在线编辑插件配置文件
- **地图管理**：上传/应用/重命名第三方地图，软链接接入 addons，不碰其他文件
- **备份管理**：实例卡片与已安装插件整体备份，一键恢复，完成可自定义命名
- **文件管理**：网页浏览、编辑、上传服务器文件
- **安全认证**：独立登录认证；Claude 风格亮/暗双主题

## 🚀 快速启动

```bash
# 1. 上传项目到云服务器（如 /opt/l4d2-panel）后进入目录
cd /opt/l4d2-panel

# 2. 交互式菜单：安装系统依赖 → 配置面板信息 → 启动面板
bash scripts/manage.sh
```

启动后访问 `http://服务器IP:8080`（端口可在菜单"配置面板信息"中修改，记得放行防火墙/安全组）。

日常启停/重启/查状态都在 `bash scripts/manage.sh` 菜单中完成；日志查看：

```bash
tail -f panel.log          # 查看日志文件
screen -r l4d2_panel       # 进入面板会话（Ctrl+A 再按 D 返回终端）
```

## ⚙️ 配置要点

- **面板账号/端口**：首次运行用菜单"配置面板信息"生成 `.env`（账号密码必填，端口默认 8080）
- **服务器实例**：全部在"实例管理"页在线维护，游戏模式留空默认 coop；运行中的实例需先停止才能改名/删除
- **Steam 账号**：服务端支持匿名下载，通常无需配置；必要时在 `.env` 填 `STEAM_USER` / `STEAM_PASSWORD`
- **服务端目录**：默认 `/home/steam/l4d2server`，`.env` 中 `SERVER_ROOT` 可改；同时是"文件管理"页根目录

更多可配置项见 `.env.example` 内注释。

## 🧩 插件导入（唯一判定标准）

插件包只要**文件夹内直接包含 `left4dead2` 目录层**即被识别为一个插件——不看内容性质、不要求含 .smx、不校验内部路径：

- 入口：文件管理 → 可安装插件目录（`data/Available_Plugins/`），上传压缩包后点「识别导入」；文件夹上传完成自动触发
- 兼容 JSGME 整合包（自动穿透外壳，排除 `!BACKUP`/`!INSTLOGS`）；无层的直根包与裸 .smx 不入库，拒绝文案附封装示例
- 与已有插件同名自动追加序号；未确认导入的暂存包 6 小时后自动清理
- 插件管理页可批量装卸；「配置」按钮可直接编辑插件文本配置（.cfg/.txt/.ini，≤1MB）
